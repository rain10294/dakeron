  3. 열린 상자에서 아이템 획득 후 합성에 활용

🧪 상인 판매 물품

포션·신속 포션, 무기·방어구·장신구, 포탈 나침반 또는 상인 두루마리 등이 랜덤으로 등장.

구매 순서!　포션·나침반·상인 두루마리를 먼저 구매하고, 무기·방어구·장신구를 나중에 사는 게 좋아요. 장비류를 구매하면 상인이 무작위 위치로 순간이동해요.
포션 소지 제한

종류별 최대 3개. 영상 예시는 체력 포션 3개 + 신속 포션 3개 = 총 6개. 초과 소지 시 낮은 등급부터 자동 버림.

상인 두루마리

우클릭하면 상인의 위치를 찾는 데 도움을 주는 아이템.

🌀 포탈·층 이동

파밍만큼 중요한 다음 층 진출

3차 테스트 참고
12분
1·2층 라운드 제한시간
4분 남음
다음 층 포탈 등장
20초
우클릭 후 이동 준비 시간
  1. 포탈이 나타난 다음 층 탐사용 나침반 사용
  2. 나침반 우클릭 → 짧은 흰 파티클 방향 확인. 3인칭에서 정지 상태로 보는 게 유리
  3. 포탈 우클릭 → 가동하는 사람은 20초간 움직이지 않기
  4. 팀전이라면 살아 있는 팀원 전원이 같은 방에 있어야 함. 다른 팀원은 같은 방 안에서 이동 가능
  5. 시간 내 이동 못 하면 해당 층에 남은 플레이어 사망 처리
포탈 수는 제한적!　다른 팀이 먼저 사용하면 남은 포탈이 줄어들어요. 포탈이 열리는 시각부터 팀원과 함께 이동 준비를 하는 게 좋아요.

❤️ 부활·생존·자기장

초반 안전시간과 3층 최종 결전

3차 테스트 참고
초반 5분 안전시간

팀전에서는 안전시간 중 팀원 둘 다 죽어야 부활. 부활할 때 무작위 시작 무기를 받는 패널티가 있음.

층 진출 시 팀원 부활

안전시간 이후 팀원이 죽어도 살아 있는 사람이 다음 층에 오르면 사망한 팀원이 부활할 수 있음.

3층 자기장　3라운드 시작 2분 후부터 약 4분간 안전구역이 좁아짐. 바깥 피해가 매우 강해서 자기장 안에서 버티는 전략은 위험. 지도와 깃발을 보고 빠르게 안전구역으로 이동!

📋 오늘 OT 확정 기록

오늘 새로 전달된 내용만 별도 보관

오늘 OT 확정
01 방 종류와 기본 파밍

방은 작은 방, 중간 방, 큰 방 총 3종류. 큰 방은 보스방. 방의 몬스터를 모두 잡으면 박스(보상 상자)가 등장하고, 상자에서 얻은 아이템을 합성하면서 성장.

02 층별 상자 티어

1층은 기본 1티어 상자. 1층 보스방만 예외적으로 2티어 상자가 나올 수 있음. 2층은 2티어 상자만 등장한다고 안내됨.
